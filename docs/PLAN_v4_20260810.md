## 3. PRED-R0:Causal Regime Transfer Audit(新,最高优先级研究线)

> 目标:把 §2.1 的发现从"观察"变成"有门禁的、跨 held fold 验证的证据",并据此定向后续算力。

### 3.1 Frozen Setup

**Regime 特征(origin 因果,只用 `<= origin`):**
- BF 总气 level(过去 1/2/4/8/24h)
- BF 总气 slope(过去 8 点)
- BF 总气 volatility(过去 8 点 rolling std)
- generator_1 ramp、generator_all ramp(过去 8 点)
- holder level / slope
- blast/coke/converter balance

**Regime 定义(阈值只在 `< dev_01` 拟合一次,冻结):**
- Gas: HIGH/MID/LOW = BF 总气 P75/P50/P25
- Ramp: STABLE/NORMAL/RAMP = 过去 8 点 ramp P25/P75
- 组合单元:≤ 6 个(HIGH_STABLE, HIGH_RAMP, HIGH_NORMAL, MID_STABLE, LOW_STABLE, OTHER)

**三口径(所有候选必须同时报):**
- **Metric A 全 dev pooled** —— robustness floor,永不删除
- **Metric B 硬 regime 匹配** —— 解释用
- **Metric C regime 连续加权 MAPE** —— 主指标
  - `w(origin) = p(regime=HIGH_STABLE | X) / p(X)`
  - **density-ratio / regime-probability 模型只允许 `< dev_01` 冻结拟合**(第一版直接冻结在 `< dev_01`,最干净);评估 held `dev_k` 只 transform、不 fit
  - 若 `< dev_01` 样本不足,升级路径 = expanding earlier-fold(`dev_1..k-1` 才 fit,held 不参与),须显式记录升级理由
  - classifier 只喂合法协变量,**禁止喂 actual / APE / 谁赢 / leaderboard**
  - 输出 cell_ESS / origin_ESS / day_ESS 与 matched-day count

**阶段分离(方法学洁净):**
- Phase 1:冻结 regime 定义 + 阈值 + density 模型(均在 `< dev_01`),完全不加载任何候选误差。
- Phase 2:才载入 A61/X3/SAFE60 OOF,输出证据表。

### 3.2 Baseline
A61 / SAFE60 / aggressive 三口径各报。

### 3.3 Gate
PRED-R0 是审计,无 promotion gate。输出:
1. 三口径 × 三候选 pooled/delta
2. per-regime × per-target 证据表
3. "g1→A61、gall→X3 in HIGH_STABLE" 逐 fold 稳定性(≥ 14/19 fold 同方向才算稳定)
4. ESS / matched-days / bootstrap

### 3.4 决策
- 规律跨 held folds 稳定 → `PASS → 启动 PRED-R1`
- 不稳定 → `STOP_PRED_R1`,只保留 gall 主线(PRED-3)

## 6. PRED-R1:Regime-Conditional Target Blend(门禁后)

### 6.1 触发
仅当 PRED-R0 §3.4 PASS(规律跨 held folds 稳定)。

### 6.2 Frozen Setup
**R1-A 全局 per-target blend(control,先跑):** 不看 regime,forward nested 只从同一固定池选 g1/gall 权重。
**R1-B regime-conditional per-target blend:** 才使用 HIGH_STABLE 规则。

规则形式(冻结):
```
if regime == HIGH_STABLE:
    g1  → A61-heavy
    gall → X3-heavy
else:
    SAFE60(0.60/0.40)
```
权重**重导出**用 forward nested:
- held `dev_k` 只看 `dev_1..k-1` 的 HIGH_STABLE
- 固定池(探索后冻结,见 §6.4):g1 X3 ∈ {0, 0.2, 0.35};gall X3 ∈ {0.4, 0.6, 0.75}
- 到 held `dev_k` 打分
- 方向成立才冻结具体权重

**采纳判据(防"target 异质性"被误认成"regime 异质性"):**
- 先算 R1-A 的 conditional marginal gain
- 只有 R1-B 相对 R1-A 的**额外贡献 ≥ 0.015pp** 才上 regime 复杂度;否则直接用更简单的 R1-A 全局 per-target blend

### 6.3 Gate
- regime-weighted improvement ≥ 0.020pp
- bootstrap P ≥ 0.80(probe)
- full dev regression ≤ 0.030pp
- worst matched-day regression ≤ 0.150pp

### 6.4 禁忌与审计口径
- 禁止事后从池外挑权重(§2 曾观测的 0.35/0.75 数字本身不得直接成为预注册权重,必须 forward 重导出)
- **审计口径明确:候选池是"探索后冻结的有限池",不是完全未见数据前的预注册**(candidate pool frozen after exploratory development evidence, not prospectively pre-registered before all development inspection)
- 禁止用测试画像定义 regime 或权重
- 未过 gate 不得标记正式候选身份

### 8.1 ESS 门禁(时序诚实)
- 同时输出:`cell_ESS`、`origin_ESS`、`day_ESS`、`matched_days`
- **bootstrap / 晋级信赖条件:`matched_days ≥ 8` 且 `day_ESS ≥ 5`**(否则 5000 次 bootstrap 只是在反复抽同样的几天,不产生统计信息)
- `cell_ESS ≥ 200` 仅作 coverage check,不能替代时序支持
- 不足 → `INSUFFICIENT_TEMPORAL_SUPPORT`,只能作方向性证据,不晋级
- 现状 HIGH_STABLE 约十几个连续高气日,务必先算 day_ESS 再谈任何 regime 结论

### 8.2 条件边际阶梯(防收益重叠)
```
B0 = 当前合法 baseline
B1 = B0 + SAFE60
B2 = B1 + per-target blend(仅 PRED-R1 过)
B3 = B2 + calibration
B4 = B3 + gall residual
```
每一步只报 conditional marginal gain;不允许把各线独立收益直接相加。
